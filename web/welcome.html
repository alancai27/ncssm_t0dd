T0dd

How this works

T0dd is a tutor for NCSSM CS courses. It has your course modules and cites them when it answers, so the help matches what you were taught in class.

It is not a code generator and it is not a general chatbot.

It does not give solutions

If you ask for assignment code, you get this instead:

Solution withheld That would have been the answer to the assignment. Try the module below, then tell me where you get stuck.

This also applies to plain English. Writing out the steps of an algorithm is still a solution, so it gets withheld too.

T0dd will explain concepts, show you language syntax, and help you find mistakes in work you already did.

How to ask questions

Questions work better when you say what you already tried.

Less useful "just give me the code for findMax"
More useful "my findMax returns 0 for [3, 9, 2]. i initialized max to 0. why does that break?"

Include what you tried, what you expected to happen, and what actually happened.

Conversations are recorded

Every conversation is saved, and the instructor for your course can read it.

This is the reason T0dd is allowed on graded work when other AI tools are not. Instructors can approve it because they can check how it was used.
